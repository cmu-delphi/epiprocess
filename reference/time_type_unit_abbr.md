# Get an abbreviation for the "units" of `unit_time_delta(time_type)`

For use in formatting or automatically naming things based on
`time_delta_to_n_steps(time_delta)` for a `time_delta` between times of
time type `time_type`.

## Usage

``` r
time_type_unit_abbr(time_type)
```

## Arguments

- time_type:

  str

## Value

str
