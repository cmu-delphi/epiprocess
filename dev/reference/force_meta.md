# Manually override `geo_type` and/or `time_type` metadata

Manually override `geo_type` and/or `time_type` metadata

## Usage

``` r
force_meta(x, geo_type = NULL, time_type = NULL)
```

## Arguments

- x:

  an `epi_df`

- geo_type:

  optional; new `geo_type` string

- time_type:

  optional; new `time_type` string

## Value

`x` with updated metadata
