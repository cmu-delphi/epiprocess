# Force `x` with regular console output silenced; return invisibly

Does not silence the message stream (which is normally
[`stderr()`](https://rdrr.io/r/base/showConnections.html)).

## Usage

``` r
quiet(x)
```

## Arguments

- x:

  argument to [`force`](https://rdrr.io/r/base/force.html)

## Value

result, invisibly
