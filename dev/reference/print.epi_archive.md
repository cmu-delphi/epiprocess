# Print information about an `epi_archive` object

Print information about an `epi_archive` object

## Usage

``` r
# S3 method for class 'epi_archive'
print(x, ..., class = TRUE, methods = TRUE)
```

## Arguments

- x:

  An `epi_archive` object.

- ...:

  Should be empty, there to satisfy the S3 generic.

- class:

  Boolean; whether to print the class label header

- methods:

  Boolean; whether to print all available methods of the archive
