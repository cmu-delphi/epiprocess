# epiprocess: Tools for basic signal processing in epidemiology

This package introduces common data structures for working with
epidemiological data reported by location and time and offers associated
utilities to perform basic signal processing tasks. The package is
designed to be used in conjunction with \`epipredict\` for building and
evaluating epidemiological models.
